# amazon-prime-eda-project
# 🎬 Amazon Prime Video Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs an in-depth Exploratory Data Analysis (EDA) on the **Amazon Prime Video** catalog using Python. The primary objective is to evaluate content diversity, regional distribution, historical scaling, and audience engagement to uncover actionable streaming platform insights.

## 🛠️ Tools & Technologies Used
* **Python** (Pandas, NumPy) for data manipulation and cleaning.
* **Matplotlib & Seaborn** for data visualization.
* **Google Colab & Jupyter Notebooks** for development environment.
* **GitHub** for version control.

## 📂 Dataset Information
The analysis utilizes two primary datasets:
* **`titles.csv`**: Contains metadata on movies and TV shows available on Amazon Prime Video (release years, runtimes, ratings, genres, and production countries).
* **`credits.csv`**: Contains cast and crew details associated with the catalog titles.

## 📊 Key Insights & Findings
1. **Catalog Dominance:** **Drama** and **Comedy** emerge as the most prominent genres across the platform's inventory.
2. **Regional Expansion:** While the United States leads production volume, international hubs like India represent a rapidly growing share of content.
3. **Growth Surge:** Content acquisition and release volume experienced a sharp upward trajectory following the post-2012 digital streaming boom.
4. **Ratings vs. Popularity:** Statistical comparison between IMDb critical scores and TMDB popularity indicates that critical acclaim does not strictly dictate audience popularity, highlighting the need for independent marketing strategies.

## 🚀 How to Run the Code
1. Clone or download the repository.
2. Ensure `titles.csv`, `credits.csv`, and the `.ipynb` notebook are in the same folder.
3. Open the Jupyter Notebook and run the cells sequentially.
